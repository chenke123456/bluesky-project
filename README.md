# Blue-projects

Blue -projects是一个面向现实社会问题的未来城市梦想生成器。

它不是游戏，而是把“模拟城市”的系统思维搬到现实中，用工程师思维、AI 方案生成、节点化推演和专业仿真，去把想法变成可以讨论、可以计算、可以优化、可以落地的蓝图方案。

## 项目目标

Blue 的目标不是做单一工具，而是把多个看似不同的蓝图生成器组合成一个互相关联的工程系统：

- 机械蓝图生成器
- 建筑蓝图生成器
- 木工蓝图生成器
- 装修蓝图生成器
- 灾害蓝图生成器
- 风水蓝图生成器
- 菜肴蓝图生成器
- 人体蓝图生成器
- 花园蓝图生成器
- 化工蓝图生成器


你可以尽情的想象，用这个平台搭积木，把社会问题用沙盘推演，我很喜欢excalidrew和comfyui的思想，我想把他们的思想融入进去，这些生成器不是孤立存在的。机械结构会影响建筑空间，建筑布局会影响装修方案，装修材料会影响安全与成本，灾害评估会反过来约束建筑和机械设计，风水/环境感知会影响居住体验与空间选择。

Blue 要做的是把这些关系组织起来，形成一个可推演、可对比、可迭代的“现实方案生成系统”。它既可以处理生活中的具体事务，也可以用于教育、科研和更大尺度的城市与国家发展战略规划。

## 核心定位

- 面向现实问题的蓝图生成系统
- 多专业协同的工程推演平台
- 基于节点思想的决策工作流
- AI + 计算 + 仿真驱动的方案优化工具

## 总体方案

Blue 的完整流程可以概括为：

```text
用户目标
  -> 需求解析
  -> 问题拆解
  -> 多蓝图生成
  -> 节点计算
  -> 专业仿真
  -> 指标评估
  -> 循环优化
  -> 输出最终方案
```

系统不会只生成一个漂亮结果，而是保留推演过程，让用户知道方案为什么这样设计、哪里有风险、还能怎样优化。

## 六类蓝图生成器

### 1. 机械蓝图生成器

用于生成机械结构、传动方案、零部件草案和工程说明。

主要能力：

- 输入功能目标和使用场景
- 拆解机械结构和运动关系
- 生成零件清单和结构草图说明
- 给出材料、强度、加工和装配建议
- 输出可交给 CAD/CAE 软件继续处理的设计参数

典型场景：

- 家用装置设计
- 工装夹具设计
- 小型自动化设备设计
- 未来城市基础设施机械结构设计

### 2. 建筑蓝图生成器

用于生成建筑空间、功能分区、结构建议和城市片区方案。

主要能力：

- 输入人口、用地、功能和预算约束
- 生成建筑布局和空间组织
- 分析采光、通风、动线、安全和成本
- 联动灾害节点进行抗震、防洪、防火评估
- 输出建筑方案说明和初步指标

典型场景：

- 住宅规划
- 学校、医院、社区中心设计
- 产业园区和科研园区规划
- 未来城市功能区设计

### 3. 木工蓝图生成器

用于生成家具、木结构、收纳系统和小型空间构件方案。

主要能力：

- 输入尺寸、用途、材料和预算
- 生成木工结构、板材切割建议和装配顺序
- 计算用料、成本和加工难度
- 与装修蓝图联动，保证风格、尺寸和施工顺序一致
- 输出施工说明和材料清单

典型场景：

- 家具设计
- 收纳柜设计
- 木屋和轻型结构设计
- 室内空间功能优化

### 4. 装修蓝图生成器

用于生成室内空间、材料、施工顺序、预算和效果方案。

主要能力：

- 输入户型、生活习惯、预算和审美偏好
- 生成空间布局、材料选择和施工计划
- 分析水电、采光、通风、隔音和安全
- 与木工、建筑、风水节点联动
- 输出装修清单、预算表和施工步骤

典型场景：

- 家庭装修
- 办公空间改造
- 民宿、商铺和公共空间设计
- 老旧房屋翻新

### 5. 灾害蓝图生成器

用于识别风险、生成应急方案，并反向约束建筑、机械和城市设计。

主要能力：

- 分析地震、洪水、火灾、台风、内涝、高温等风险
- 生成避险路线、应急物资和恢复方案
- 对建筑、装修、设备和城市布局提出安全约束
- 输出风险等级、薄弱点和优化建议

典型场景：

- 城市防灾规划
- 社区应急预案
- 建筑安全检查
- 工厂和园区风险评估

### 6. 风水蓝图生成器

这里的风水不是迷信化判断，而是把环境感知、空间心理、光照、通风、动线、噪声、绿化和居住体验纳入设计。

主要能力：

- 分析空间朝向、采光、通风、噪声和动线
- 评估居住舒适度和心理感受
- 给出空间优化建议
- 与建筑、装修和生态节点联动
- 输出环境体验说明

典型场景：

- 住宅环境优化
- 办公空间舒适度提升
- 社区公共空间设计
- 教育和康养空间设计

## 节点化执行方案

Blue 的后端采用节点思想。每个节点负责一个明确任务，多个节点连接成完整工作流。

### 基础节点

- 目标输入节点：接收用户想解决的问题
- 需求解析节点：提取功能、场景、预算、尺寸、时间等信息
- 约束识别节点：识别材料、空间、法规、成本、安全等限制
- 任务分派节点：决定调用哪些蓝图生成器

### 专业节点

- 机械设计节点
- 建筑规划节点
- 木工结构节点
- 装修方案节点
- 灾害风险节点
- 环境体验节点

### 评估节点

- 成本评估节点
- 安全评估节点
- 可施工性评估节点
- 能耗评估节点
- 舒适度评估节点
- 风险评估节点

### 优化节点

- 冲突检测节点
- 多方案对比节点
- 参数调整节点
- 迭代优化节点
- 最终报告节点

## 一个具体工作流示例

用户输入：

```text
我想设计一个未来社区，既能居住，也能种植，还要防灾、节能、适合老人和孩子生活。
```

系统执行：

1. 需求解析节点提取目标：居住、种植、防灾、节能、适老、儿童友好
2. 建筑蓝图生成器生成社区空间结构
3. 装修蓝图生成器生成室内生活单元
4. 木工蓝图生成器生成家具和收纳方案
5. 机械蓝图生成器生成自动种植、升降、运输等装置
6. 灾害蓝图生成器评估洪水、火灾、停电和疏散风险
7. 风水蓝图生成器评估采光、通风、噪声、绿化和心理舒适度
8. 指标评估节点比较成本、安全、效率、舒适度和可落地性
9. 优化节点调整参数并重新生成方案
10. 最终报告节点输出完整蓝图方案

## 评价指标

Blue 不只看“能不能生成”，更看“方案是否更优”。

核心指标：

- 成本
- 安全
- 可施工性
- 能源效率
- 空间利用率
- 材料利用率
- 维护难度
- 灾害韧性
- 居住舒适度
- 教育与科研价值

## 前端设计

前端应围绕“目标输入、过程可见、结果可改”来设计。

主要页面：

- 首页任务输入
- 项目列表
- 蓝图生成器选择
- 节点工作流页面
- 方案预览页面
- 指标对比页面
- 历史版本页面

交互重点：

- 用户可以输入一个梦想或问题
- 系统自动拆成多个节点
- 用户可以看到每个节点做了什么
- 用户可以调整约束重新生成
- 用户可以比较多个方案

## 后端设计

后端第一阶段不需要一开始就接入所有专业软件，可以先实现轻量原型：

- Python 节点执行器
- JSON 工作流描述
- 蓝图生成节点
- 指标评估节点
- 结果报告节点
- Web API

后续再逐步接入：

- CAD 建模软件
- CAE 仿真软件
- 建筑能耗分析工具
- GIS/地图数据
- 材料与成本数据库

## 数据结构建议

一个方案至少包含：

- 用户目标
- 场景条件
- 约束条件
- 调用的蓝图生成器
- 节点执行记录
- 生成的方案
- 评价指标
- 风险提示
- 版本信息

## 落地路线

### Phase 1：最小可用原型

目标：证明“多蓝图 + 节点推演”可以跑通。

要做：

- 保留当前 mini_comfy 节点执行框架
- 新增六类蓝图节点
- 新增指标评估节点
- 新增示例工作流
- 前端展示输入、节点、结果

输出：

- 一个可以在浏览器运行的原型
- 用户输入目标后生成结构化方案
- 页面展示节点执行结果

### Phase 2：工程化方案生成

目标：让结果更像真实方案。

要做：

- 建立材料、成本、安全、舒适度等规则库
- 支持多方案生成
- 支持方案对比
- 支持版本回放
- 支持导出 Markdown/PDF 报告

输出：

- 多方案对比
- 指标评分
- 风险清单
- 可执行建议

### Phase 3：专业软件接入

目标：让 Blue 从“方案生成器”升级为“工程验证平台”。

要做：

- 接入 CAD/CAE/建筑仿真工具
- 接入真实地理、气候、材料和成本数据
- 支持参数化建模
- 支持自动仿真与优化

输出：

- 工程级蓝图
- 仿真结果
- 优化报告
- 面向科研和教育的案例库

## 当前项目优先级

2. 把 Text/Uppercase/Add 示例节点替换成蓝图节点

5. 输出结构化方案结果

## 一句话总结

Blue 是一个把机械、建筑、木工、装修、灾害和环境等体验连接起来的未来城市梦想生成器，用 AI 生成方案，用节点组织逻辑，用仿真验证结果，用工程师思维把梦想推向现实。
