# Blue

Blue 是一个面向现实社会问题的未来城市梦想生成器。

它不是游戏，而是一个像乐高积木一样可以拼装、组合、试错和重来的系统。用户可以把机械、建筑、木工、装修、灾害、风水、种植、人体、菜肴等蓝图模块像积木一样搭起来，生成面向现实生活的方案。

Blue 必须遵守两类底层规则：

- 阴阳平衡法则
- 物理定律

这两类规则不是装饰，而是所有方案的前置约束。

## 项目目标

Blue 的目标不变：把现实中最急需解决的问题，变成一个可建模、可推演、可对比、可优化的系统。

这些蓝图模块不是孤立的，它们彼此关联，像积木一样互相影响：

- 机械蓝图生成器
- 建筑蓝图生成器
- 木工蓝图生成器
- 装修蓝图生成器
- 灾害蓝图生成器
- 风水蓝图生成器
- 菜肴蓝图生成器
- 人体蓝图生成器
- 花园蓝图生成器
- 化工蓝图生成器

你可以把它理解成一个“现实世界积木盒”：

- 想做一个家，先拼结构
- 想做一个社区，先拼关系
- 想做一个城市，先拼系统
- 想做一个未来生活方式，先拼蓝图

Blue 要做的是把这些模块组织起来，形成一个可以搭、可以拆、可以重组的现实方案生成系统。

## 为什么要做成积木式

因为现实问题本来就是模块化的。

一个城市不是一个整体按钮，而是一堆互相连接的块：

- 住房影响通勤
- 通勤影响健康
- 健康影响教育
- 教育影响产业
- 产业影响能源
- 能源影响灾害韧性
- 灾害又反过来影响建筑和装修

Blue 让这些关系变成看得见、拼得起来的积木。

## 设计理念

Blue 采用工程师思维，但表达方式要有趣、轻松、直观。

1. 先定义目标
2. 再拆成积木
3. 再连接积木
4. 再跑推演
5. 再看反馈
6. 再调整组合
7. 最后形成更优解

它关注的不是“复杂”，而是“清楚、好玩、能拼、能改”。

## 法则层

在 Blue 里，法则层比蓝图层更底层。

### 阴阳平衡法则

这里的阴阳法则，不是神秘化表达，而是对系统平衡的描述：

- 动与静要平衡
- 开放与收敛要平衡
- 明与暗要平衡
- 热与冷要平衡
- 快与慢要平衡
- 公共与私密要平衡
- 集中与分散要平衡

阴阳法则的作用，是避免方案走向单一极端，让城市、房屋、空间和生活方式更稳定、更舒适、更可持续。

### 物理定律

所有蓝图都必须服从物理定律：

- 结构要承重
- 材料有强度极限
- 能量不能凭空产生
- 热量会传递和耗散
- 空间有尺度限制
- 运动有惯性和摩擦
- 人体有舒适范围和使用边界

物理定律不是后验解释，而是生成方案时就必须检查的硬条件。

## 总体方案

```text
用户目标
  -> 需求解析
  -> 问题拆解
  -> 积木式蓝图选择
  -> 节点计算
  -> 专业仿真
  -> 指标评估
  -> 重新拼装
  -> 输出最终方案
```

系统会保留每一次拼装过程，让用户知道：

- 为什么这样拼
- 哪个块和哪个块会冲突
- 哪里需要换块
- 哪一组积木更稳、更省、更好玩

## 一个具体工作流示例

用户输入：

```text
我想做一个适合孩子和老人一起生活的未来社区，里面有房子、花园、种植区、应急空间和学习空间。
```

系统执行：

1. 需求解析节点提取目标
2. 阴阳平衡节点检查动静、开合、明暗、冷暖、公共私密是否平衡
3. 物理约束节点检查承重、尺度、能量、热量、材料和人体工学
4. 建筑蓝图生成器拼出社区空间
5. 木工蓝图生成器拼出家具和收纳
6. 装修蓝图生成器拼出室内布局
7. 花园蓝图生成器拼出种植和活动区
8. 灾害蓝图生成器拼出防灾和应急积木
9. 风水蓝图生成器拼出采光、通风和舒适度优化
10. 指标评估节点比较不同拼法
11. 优化节点重新拼装更优组合
12. 最终报告节点输出完整方案

## 落地路线

### Phase 1：积木原型

目标：先做一个能拼、能跑、能看结果的版本。

要做：

- 保留节点执行框架
- 增加积木式蓝图节点
- 增加示例方案
- 做拖拽式前端
- 输出结构化结果

### Phase 2：好玩化和系统化

目标：让它真的像一个能玩、能试、能对比的系统。

要做：

- 积木库可视化
- 方案评分
- 版本回放
- 多方案比较
- 用户自定义积木

### Phase 3：专业化接入

目标：把玩具感和工程感结合起来。

要做：

- 专业软件接入
- 真实数据接入
- 更强的仿真和优化
- 现实项目辅助落地

## 当前项目优先级

短期最应该先做：

1. 把当前项目明确成“积木式梦想生成器”
2. 做一个积木库
3. 做一个可拖拽的拼装界面
4. 保留节点推演能力
5. 输出可读、可比、可重来的方案结果

## 一句话总结

Blue 是一个像乐高积木一样好玩、孩子也能上手的未来城市梦想生成器，用节点化思维把机械、建筑、装修、种植、灾害、环境体验、阴阳平衡和物理定律拼成一个可以推演现实问题的系统。
